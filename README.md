# OpenMRS Healthcare QA Portfolio

## Overview

This repository showcases my QA approach for healthcare systems using the OpenMRS demo environment. It focuses on validating end-to-end workflows, patient data accuracy, and system behavior.

## Application Under Test

OpenMRS Demo (Electronic Medical Records System)

## Domain

Healthcare / EMR

## Scope

* Patient Registration
* Patient Search
* Clinical Visits
* Observations and Notes
* Data Validation
* Negative Testing
* Role-based Access

## Key Workflows Tested

1. Patient Registration → Search → Verification
2. Start Visit → Add Notes → Save Encounter
3. Validate Patient History and Data Persistence

## Test Artifacts

* Manual Test Cases (60+ scenarios)
* Test Plan
* Test Scenarios
* Bug Reports
* RTM
* Execution Report

## QA Focus

* Data integrity and accuracy
* End-to-end workflow validation
* Risk-based testing
* Healthcare system behavior

To demonstrate how QA ensures reliability, accuracy, and safety in healthcare systems through structured testing and real-world workflows.
